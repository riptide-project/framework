## Build your first feature, then grow with confidence

Riptide gives your server and client modules a predictable **Load → Init → Start** lifecycle. It also provides named networking, replicated state, and reusable components. You can learn one piece at a time.

## Choose the documentation that matches your package

The default learning path uses **0.8.2**, the latest stable release. **Maelstrom-3** is the latest preview. Use the [version archive](./versions/) to match the docs to your installed package.

Pick your package version in the selector at the top of every page. Examples and API names can differ between releases.
